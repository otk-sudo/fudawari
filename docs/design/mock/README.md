# 画面モックについて

このフォルダの `*.dc.html` は、claude.ai のデザイン機能（Design のアーティファクト）で作った画面モックの**ソース**です。画面の最終形（配置・文言・操作の流れ・表示の条件）を確かめるための資料として、リポジトリに控えを置いています。

## 見た目を確かめるとき

- 各ファイルは `./support.js`（デザイン機能の描画用の実行ファイル）を読み込みますが、この実行ファイルはデザイン機能の提供者のもので、利用条件が分からないため**リポジトリには含めていません**。そのため、ブラウザで直接開いても `{{...}}` の差し込みや部品の読み込み（`dc-import`）、操作は動きません。
- 描画された画面は、元のデザインのアーティファクト（https://claude.ai/code/artifact/d1547b00-65ea-4dac-9c5d-59cfebca0b10 。ユーザーのアカウントで開く）で確かめる。
- `canvas.json` に、キャンバス上の各画面の名前と配置、付箋の取り決め（権限ごとのメニュー、最新イベントだけ）がある。

## 読み方

- 画面の構造と文言は、`<x-dc>` の中の HTML を読む。`sc-if` は表示の条件、`sc-for` は繰り返し、`dc-import` は部品（例：`SideNav`、`ShipCard`、`SettingsDialog`、`ExportImage`）の差し込み。
- 操作と表示の条件は、末尾の `<script type="text/x-dc">` の `renderVals()` を読む。中の数値（札・倍率・艦）はダミーまたは説明用で、実装ではイベント定義から組み立てる。
- 各画面の右上にある「見え方の確認」（一般／協力者／管理者などの切り替え）はモック専用で、本番には作らない。
- `Matrix.dc.html`（特効マトリクス）は不採用の旧案。

モックの中身は変更しない（`CLAUDE.md`）。要件との関係は `docs/requirements.md` 3 章を参照。
